# Quickstart: Settings Search, Type Names, Clock Meaning

1. Settings → type `retention` (or `保存`) → pick the result → Capture control
   opens at "Retention and disk budgets".
2. Timeline → Filter → Type: options read Shell, HTTP, Proxy…; hover shows the
   stored type.
3. Hover the status-bar clock: "Time since this project was created (…), not
   this session".
