# Validation Quickstart

1. Seed more loot events than one page and page through every event exactly once.
2. Apply a shared filter and verify it is evaluated before the page limit.
3. Reject the initial query and confirm a retryable error replaces the empty state.
4. Reject an older-page query and confirm loaded loot and Load Older remain.
5. Run focused tests, full tests, typecheck, build and the affected desktop journey.
