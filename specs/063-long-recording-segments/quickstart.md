# Validation

Run focused Vitest recording, cast-slice, terminal rotation, export attachment/selection and command-output tests with the repository Node runtime. Test capacity with small injected budgets, then a real >50 MiB recording; do not allocate the whole raw recording for hashing.

Read a command spanning multiple parts by range and time; concatenate independently decoded frames and compare the original Unicode output. Export the recording with and without one part and compare frozen byte/hash manifests. Export >2,000 companion chunks and check the last pre-snapshot chunk is present, post-preview chunk absent.

Use one isolated Electron session for affected journeys. Run Bash/Zsh/PTy subprocess checks separately. Native Windows PowerShell/WSL and Kali installation/resize/job-control are NOT proven by Mac unit fixtures; record them as pending unless actually executed.
