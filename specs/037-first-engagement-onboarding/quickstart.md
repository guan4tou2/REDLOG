# Quickstart: First-Engagement Onboarding

1. Create a project, paste `10.10.11.0/24 *.corp.local bad$host` into scope:
   `bad$host` is flagged; the project is created with the other two.
2. Tick "ignore this machine's traffic": Settings ▸ Scope lists your IP under
   personal traffic next to `127.0.0.0/8`.
3. Run a command in the built-in terminal, click "記我的 Zsh 終端", open a new
   terminal and run the `echo redlog-ok-…` shown: the screen confirms.
4. Skip the HTTP card: the Dashboard does not suggest AI or HTTP as next step.
