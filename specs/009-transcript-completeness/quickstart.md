# Validation Quickstart

1. Seed more evidence than at least one Transcript bucket limit.
2. Open Transcript and verify it identifies a recent subset.
3. Load older evidence until the view reports the loaded set is complete.
4. Fail an older-page request and verify current rows remain with retry.
5. Copy a partial transcript and verify the Markdown states that it is partial.
6. Run focused tests, typecheck, full tests, build and Transcript E2E.
