# Quickstart: Loot Rule Time Bound

1. Install a plugin with `"lootPatterns": [{ "type": "evil", "pattern": "(a+)+$", "name": "backtrack" }]`.
2. In the built-in terminal, `printf 'aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa!'`.
3. The terminal and UI stay responsive; Settings ▸ Capture ▸ Loot detection
   marks `evil` as stopped.
