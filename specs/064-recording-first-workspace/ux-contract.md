# UX 操作與資訊架構契約

**Status**: Draft · 2026-10-26。配套：[spec.md](spec.md)。本文件是產品行為規格，不是已上線畫面或逐像素設計稿。

Activity 身分／工具分類、搜尋覆蓋、內容閱讀、片段座標、匯出快照及擷取邊界分別由 [C1](contracts/activity-projection.md)、[C2](contracts/search-coverage.md)、[C3](contracts/content-viewer.md)、[C4](contracts/evidence-anchor.md)、[C5](contracts/export-snapshot.md)、[C6](contracts/capture-boundaries.md) 細化。此處定義入口與布局；涉及資料邊界時遵守相應契約，不由頁面自行解讀。全部需求對照見 [traceability.md](traceability.md)。

## 1. 操作路徑與導覽

```text
首次：安裝／啟動 → 建立或選專案 → 接入自己的 Shell → 真實指令＋輸出＋結束碼 → 開始工作
按需：擷取來源 → 瀏覽器與 HTTPS → 路由／憑證 → 以選定用戶端驗證
日常：背景記錄 → 找到操作 → 讀內容／關聯 → 確認範圍 → 匯出 → 找回成品
```

HTTP、Scope、AI 均可稍後補；略過不代表完成。總覽的來源狀態直達日常來源設定；只有使用者選擇「接入／驗證」才顯示相應步驟，不打開整場首次引導。

| 主入口 | 內部工作 | 既有能力承接 |
| --- | --- | --- |
| 總覽 | 本專案錄製狀態、來源問題、修復、近期操作 | Dashboard、Capture Health |
| 活動紀錄 | 活動／輸入輸出／AI 對話、Session、專案搜尋與深入結果 | Timeline、Transcript、Search、Inspector、錄影索引 |
| HTTP 紀錄 | Flow、Request／Response、Headers／Body／Raw、已保存 WebSocket | HTTP History；不新增重送或掃描工作台 |
| 目標 | 相關活動、證據、Scope 判定與可追溯 Pivot 資訊 | Targets、Scope 結果；編輯規則連到 Settings |
| 證據與註記 | 截圖／附件、標記、書籤、Loot | Screenshots、Bookmarks、Loot、既有 Marker／附檔 |
| Terminal（選用） | 現有即時終端及回放 | Terminal；外部終端使用者不必先開 |
| Settings（固定） | 設定行為、來源與資料政策 | 既有設定，重新整理入口 |

目標頁是「這台的活動」，不是另一個 Scope 編輯器。證據頁不把所有東西改名 Findings。HUD 保持獨立；截圖、加檔、標記、暫停及 Export 延用全域動作，不各占主選單。

導覽次序固定，不新增拖曳排序。新實作預設快捷鍵目標為：⌘/Ctrl+1 總覽、2 活動、3 HTTP、4 目標、5 證據、6 Terminal、9 Settings；實際顯示與指令面板來自同一組定義，剩餘號碼不需湊滿。現行舊編號在新版實作完成前保持現狀，不加舊版本相容開關。

## 2. 活動工作區

```text
活動紀錄                 [活動] [輸入／輸出] [AI 對話]
[搜尋專案…                                 ]
[類型] [來源] [時間] [目標] [進階]
[可移除條件…]

Session／結果／活動列表   │ 內容詳情    [全寬]
                         │ 原始內容、結果、來源及相關證據
```

這是結構示意，不是要求每層各加一張卡片／標題／解說。正常畫面只顯示有用資訊；無條件時不留空標籤區，無 Session 需求時不硬留側欄。

- 活動：單一時間排序列表取代泳道，預設最新優先；保留時間定位、來源與關聯。
- 輸入／輸出：連續閱讀指令與結果。長內容可全寬，不壓在狹窄 Inspector。
- AI 對話：選 Claude Code／Codex 及其 Session；閱讀 Prompt、回答與可展開工具操作，不新增 AI 主頁。
- Session 清單可收合。選 Session 是閱讀操作，不安裝或啟用來源；一個 Session 可跨目標，不能把它強綁一台。
- 點資料列預設開詳情；跳另一工作區使用明確動作。側欄與全寬共用同一內容、選取、內容搜尋及閱讀位置。
- 窄視窗以單欄詳情接替列表並保留返回；不硬塞列表＋詳情＋Session 三欄。

「操作紀錄／原始事件」是顯示層級；診斷放進階條件，不新增第三套主工作區。Thinking 不占一般活動獨立一列。查詢命中原本隱藏內容時，仍顯示命中，不要求猜開關。

## 3. Activity 投影、排序與歸因

### 群組規則

- 保留 Activity 的穩定身分、所有來源事件參照、Session／專案、配對狀態、關聯依據及命中資訊。
- Shell 優先以明確 command identity＋來源 Session 配對；只有缺少可靠身分時保持獨立。不能以 PID＋同文字跨 Session 折掉別筆起點。
- AI 以提供者＋Session＋工具／訊息的穩定身分配對。缺 Call、缺 Result、仍有可信活動訊號、明確中斷各自表示。
- AI 及獨立 Shell／網路證據只有明確來源關係才可在同一操作下並列；相同命令、IP 或時間鄰近只可列相關背景。
- 群組只改閱讀，不能改事件、tier、時間、雜湊或憑空建立因果。正常結果晚到更新既有群組，不重複新增操作。
- 分頁邊界可跨群組；繼續載入後按穩定身分合併，不能丟結果、重複群組或只在當前一頁配對。

### 四種不同資訊

| 資訊 | 問題 | 顯示限制 |
| --- | --- | --- |
| 操作類型 | 做了什麼？ | 指令、網路、對話、證據、安全、系統；未知保留「其他」通用事件。 |
| 提供者／工具 | 哪個工具回報？ | Claude Code、Codex、Shell 等；名稱不證明成功執行。 |
| 發起者 | 誰要求執行？ | 僅依明確資料；登入 operator 身分不自動證明每次執行由人輸入。 |
| 觀測來源／關聯 | RedLog 怎麼知道？ | 獨立觀測、AI 回報、候選／僅時間相關、未知須區分。 |

只有明確的執行工具可分類為「指令＋Claude Code」。一般回答、讀檔工具及未知工具不假裝 Shell 執行；未知工具仍可由對話中的「工具操作」或通用事件找回。

活動顯示實際時間／區間；查詢命中時間與群組背景不同時可辨識。固定同時事件的排序依據，不因切換檢視而變。閱讀中不立即重排選中項；新資料透過既有更新／跟隨機制合併。

### 預設收斂

| 內容 | 一般操作紀錄 |
| --- | --- |
| 指令及其結果、明確工具操作 | 一個主要操作，展開可讀來源與輸出。 |
| HTTP 交換、Pivot、人工截圖／附件／Marker | 保留有用摘要；高頻來源可分組，但每筆可取回。 |
| AI 長對話、週期截圖、高頻 DNS／C2 | 摘要或收合；不以抽樣冒充完整。 |
| 初始化、一般診斷、來源內部快照 | 預設不逐列展示；原始事件及搜尋可取回。 |
| 暫停／恢復、擷取缺口、保存失敗、工具中斷、真正 Scope 違規 | 始終能看見其影響，不受一般噪音收合隱藏。 |

「沒有結束紀錄」顯示未知／未完成紀錄；只有來源仍在運作的可信證據才能標成執行中。搜尋／顯示模式造成的省略須與擷取缺口分開。

## 4. 查詢、計數、覆蓋與內容搜尋

- 專案搜尋與常用篩選是一個查詢上下文；維度之間 AND、同維度複選 OR，進階語法保留。新加的條件須先有一致資料語意，不能只在一頁上篩。
- 常用：操作類型、實際來源、時間、目標。進階：提供者／發起者、Session、結果、完整性、網頁 Scope、證據層級及既有隱私過濾。無資料依據的選項不顯示為已可用。
- 結果狀態至少分原始命中、群組、相關背景、已載入部分。精確總數不明時只報已知部分與有更多，不先取 N 筆再冒充全域結果。
- 查詢命中集合、關聯背景與群組來源分開：命中 Result 可補 Call 作背景，但不把背景算命中；跨時間區間的上下文不假裝滿足原條件。
- 清條件、取消查詢、重試均保留可用輸入；慢的舊回覆不能覆蓋新查詢。返回保存原條件及命中定位。
- 事件、長內容索引、錄影索引的覆蓋分開核對。未索引、無權讀、失敗、未支援的條件皆不能被「零結果」掩蓋。
- 錄影缺少對應篩選中繼資料時，排除該部分並明示受限；不假裝它通過目標／來源條件。
- 正常完整搜尋不新增一整段覆蓋說明；只有限制或失敗才顯示必要狀態與可行操作。深入結果使用同一查詢，不另開另一套條件。
- Cmd/Ctrl+F：活動列表聚焦專案搜尋；內容閱讀時查找目前內容並標明範圍。清除局部查找不清專案條件。
- 命中片段必須位於可追溯來源。高亮只作顯示，不改輸出原文或複製內容。

## 5. 指令、輸出與 AI 對話閱讀

| 已知狀況 | 必須呈現 |
| --- | --- |
| 已保存且可讀 | 實際內容、可用的大小／範圍、來源與取出方式。 |
| UI 預覽受限 | 部分預覽及繼續讀取／完整檢視；不說原始資料已截斷。 |
| 真正保存截斷或缺口 | 已知保存／遺漏量、來源及原因；未知不填零。 |
| 僅中繼資料／未擷取 | 可取得的指令／狀態；不可用空字串暗示零輸出。 |
| 未解密 | 實際取得的網頁／連線中繼資料；不顯示明文已保存。 |
| 尚未載入／讀取失敗 | 分開顯示，失敗可重試；不改成沒有內容。 |
| 附件被清理／遺失 | 原參照及可查清理資訊；不聲稱現在仍可完整讀取。 |
| 無終止／結果紀錄 | 未完成或未知；不由缺少事件推定執行中／失敗。 |

- 快速閱讀與完整檢視使用同一內容來源，長內容分段讀取。轉全寬不能重設查詢或重新啟動擷取。
- 真正分離的 stdout／stderr 可各自閱讀；只有來源具有可驗證的交錯順序才提供真實合併。PTY 混流用終端畫面／合併輸出，不編造兩路。
- 指令輸入是已觀測 command／argv；互動 stdin 不因此被宣稱全記錄。回放使用已保存畫面，不能推算遠端每道指令或攔截密碼。
- AI User／Assistant 連續閱讀，長文按需收合；工具顯示名稱與狀態、展開 Input／Result。原始事件與回報／觀測來源可查。
- Thinking 僅顯示實際可取得且已授權保存的資料。預覽不叫完整推理；不顯示、不建立事件、不保存原文是不同政策。
- 內容複製與下載保持可理解的範圍；複製可讀文字與取出原始 bytes 是不同動作，遵守既有秘密揭露／隱私規則。
- 不渲染可執行內容；外部連結由使用者明確操作。歷史 ANSI／Markdown 不得自動改剪貼簿、執行腳本或連外追蹤。

## 6. Settings 與來源唯一入口

| 分類 | 內容 |
| --- | --- |
| 擷取來源 | 內建擷取／外部整合；來源接入、權限、真實驗證及修復。 |
| 專案與範圍 | 專案資訊、網頁包含／排除、IP 曝光相關政策；概念不混用。 |
| 資料與隱私 | 保留、遮蔽、既有 Loot 規則、完整性。 |
| 介面與操作 | 語言、時間、密度、HUD、捷徑。 |
| 進階與系統 | 第三方外掛信任、診斷、版本及既有更新。 |

這五項是導覽歸類，不是五個所有選項全攤開的超長頁面。保留設定搜尋、目的導覽、深連結與欄位定位。按實際控制需求重用元件，不預先要求四個新抽象元件。

- 內建：指令／終端、瀏覽器與 HTTPS、截圖，以及預設關閉的既有主機監看。核心不要求安裝 Plugin；依賴未備妥仍提供真實準備操作。
- 外部：Claude Code、Codex；既有外部工具依它的實際啟動方式接入。AI 預設不安裝、不讀取、不授權；不新增其他 AI 或協定解析器。
- 官方 AI 的安裝、移除、本專案授權與排除 Session 都從來源入口完成。進階外掛頁不再提供第二套官方開關；第三方信任與可執行權限保留在進階管理。
- 顯示本機與本專案兩個實際作用範圍。移動欄位不把 per-project 設定偷偷變全機，也不把全機停止偽裝只影響本專案。
- Shell 接入、選 Terminal App、本機整合安裝／信任屬對應本機環境；AI 工作目錄／Session 排除、網頁 Scope 屬本專案。其他保存／HUD／偏好按現有實際儲存範圍明示。
- AI 原始對話留在原工具；允許的工作目錄決定授權；已收錄證據屬 RedLog 專案。來源位置正常時自動辨識，非標準位置或找不到時才展開修改；不要求新手找 JSONL。
- 每個來源依實際狀態只給下一個主要動作。指令及輸出證明、代理及此 client 的 HTTPS 證明分開，不加一個籠統綠勾。
- 失敗在受影響控制旁顯示原因、影響及具體修復。可用狀態／按鈕表達就不再加重複說明。
- 暫停、停止、移除整合、刪資料不可互當同義字。移除整合不刪來源工具原始資料或專案既有證據。

## 7. 目標、證據與匯出

- 目標頁呈現 canonical 目標的已觀測活動。來源歸因為明確／候選／未知；事件數、操作數、命令數不可混稱。
- 只看某目標不修改正在記錄的目標。規則編輯回 Settings；未設定／未知／無已觀測違規／讀取失敗及後來重算分開。
- 網頁 Scope 同時涵蓋 HTTP／HTTPS，但不當指令的刪除政策。未設定 Scope 可以經明示後交付，不標成「全部安全」。
- 證據區保留四類：截圖與附件、Marker、Bookmark、Loot。Marker 走正式修訂；Bookmark 可編刪；Loot 是線索，不是 Finding。
- 選取輸出建立 Marker 時，保存 Event、附件與可確認的範圍；不足以精確定位時保留來源及選取文字，標明限制。不能只靠複製短句聲稱原證據完整。
- 檔案變更通知與已保存當次版本分開；未知來源的附件可讀，但不自動硬綁命令。
- 匯出維持單一入口與真實預覽。常用證據包／HAR，其他格式保留進階；不新增平行交付流程。
- 目前查詢使用明確的查詢與顯示層級；操作／Session 選取須明確。收合只是顯示，不增減選取；原始命中、補足的必要上下文及附件須可在預覽核對。
- Session 作為導航群組不等於整個 Session 已勾選；不能因搜尋命中其中一個 Tool Result 就默認交付整段對話。
- 文字／格式／條件／政策或附件選取改變即重新確認預覽。執行與預覽採相同固定邊界，後來新增內容不偷偷跟著出包。
- 截圖、錄影及原始附件不宣稱能以網頁 Scope 自動清乾淨。提供逐檔排除；正式成品、驗證邊界與不完整資料可查，完成後能開啟所在位置及最近成品。

## 8. 版面與元件

- 延用既有字體、色彩、按鈕、輸入、清單、Dialog 及密度；Forensic Editorial／深色紅色只是視覺語言，不凌駕易用性與證據語意。
- 清單、來源步驟及資料工作台使用可用寬度；表單依內容定寬。禁止全頁固定窄欄造成大面積無用留白，也不為填滿畫面拉成等高大卡片。
- 主要動作位置穩定；普通清單以對齊／留白分組，不預設每項 icon＋標題＋解說＋卡片。單一項目不另加分組標題。
- 必要長內容各自捲動；標籤與動作可換行，關閉／返回／確認不可被擠出視窗。
- 載入不卸載正在輸入的欄位；狀態刷新不重置焦點。保存失敗保留輸入，重試不可重跑原攻擊命令。
- 空、零命中、讀取失敗、部分結果、禁用各有正確操作。一般畫面不加教學段落；安全、不可逆與能力界線保留短且必要的警告。
- Hover／focus／pending／success／failed 一致；顏色不是唯一訊號。動畫不延遲輸入、改變事件順序或影響擷取；尊重減少動態設定。
- HUD 仍是 IP／既有狀態用途，預設開啟。穿透的實際退出方式與焦點須真機驗證；不新增 HUD 模式。
