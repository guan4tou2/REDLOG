**Status**: NOT RUN · 2026-10-26。本表針對 Spec 064 新工作區；既有版本及 Spec 063 的結果不能直接填成新版 PASS。

## 1. 完成判定

- 每次結果記錄候選版本／ref、套件與 hash、OS／架構、來源版本、fixture、語言、視窗／App 縮放／OS DPI、操作及產出。
- 狀態使用 PASS／FAIL／NOT RUN／BLOCKED／UNSUPPORTED。略過不是通過；單平台不代表其他平台，seed 事件不證明真實 producer 或安裝。
- 以下任務全部都有涵蓋才可宣稱工作區完成；仍有必要 gate 未跑時 Spec 保持 Draft 或 Implemented，不升 Verified。
- 一般資料用合成 fixture，記憶／截圖／公開 issue 不帶真實客戶內容。原生焦點／穿透／系統授權須按真實操作驗證。

## 4. Fixture 與版面矩陣

- 小量：空專案、各來源各數筆；大量：十萬原始事件、三個終端、至少二十個來源 Session、兩個 AI 提供者。
- 已知原始命中在首／中／末頁、折疊 Result、不同輸出方向、已索引 cast、無索引／拒絕讀取 sidecar；每份 fixture 保存預期原始 IDs、群組、關聯及附件。
- 長內容：至少十 MiB 的**已保存完整**文字，另備真正截斷 fixture；不能把資料根本沒保存的案例當完整 Viewer 驗收。錄影跨至少三個實際分段。
- 對話有 Markdown／程式碼、長工具參數、binary／非 UTF-8、未知來源、重送／晚到／未配對及跨時間範圍背景。
- 視窗：800×500、960×720、1440×900、1920×1080；App 縮放 100／125／150／200%；繁中／英文、既有兩種密度、鍵盤、減少動態。選代表組合涵蓋風險，不把所有案例相乘產生重複測試。
- 尺寸以作業系統邏輯座標記錄；App zoom 與 OS DPI 分開，同一次幾何比較不可混 device／CSS 像素。程式碼／二進位閱讀區內橫向捲動可以，整窗及主要動作不可溢出。
- 同一指定機器／磁碟、同份資料，改版前後三十次代表查詢，記 p50／p95；冷／熱索引分開，索引未就緒不能偷偷當零結果。首批正確結果 p95 ≤1 秒；輸入／查詢可重現退步 >10% 必須修正或重新明確審查目標，不能直接當通過。

## 6. 測試整理原則

保留來源真實性、隱私／專案隔離、查詢完整性、配對、保存故障、雜湊／匯出、工作控制與必要焦點測試。舊泳道數量、已淘汰入口／用語及重複樣式斷言應在替換功能完成時移除或換成相同使用者任務；不加相容程式只為舊測試繼續綠。

同一穩定 fixture 和相容任務可共用一次 App 啟動；真正首次安裝、專案隔離、更新與原生權限需要獨立環境時才重開。優先驗證可觀察行為，不為每個 JSX／CSS 結構再造測試。規格／流程文件變更只做文件檢查，不為宣稱完成重跑整套 GUI。

本矩陣用於相關批次與交付驗收；小幅文案或樣式變更只跑受影響任務及必要回歸，不要求每次重跑所有平台、受測者與 GUI。
