# Quickstart: Capture Verification Contract

1. Verify Zsh on first run: the state says output is not recorded and shows
   `redlog-session` with a copy button.
2. Start HTTP capture on first run: "正在等第一筆 HTTP 請求" until a page is
   loaded in the proxied browser, then "✓ HTTP 擷取已驗證".
3. Start it and do nothing for 60 s: the reasons appear; load a page — it
   verifies.
