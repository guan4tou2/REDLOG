# Quickstart: Search on the Shared Query Contract

1. Record a corpus of queries against the current Search and keep their results.
2. Migrate, then replay the corpus and confirm each selects the same events.
3. Run one query text on Search and on the Transcript under the same shared
   filter and confirm both reach the same evidence.
4. Resolve each identifier condition from Search and confirm it agrees with the
   Transcript.
5. Enter a mistyped field prefix and confirm Search shows it was read as text.
6. Interrupt the query path and confirm Search's failure, partial and
   not-yet-indexed states are still distinct.
