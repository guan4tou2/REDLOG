# Validation Quickstart

1. Make the event search reject and verify an alert replaces the empty state.
2. Retry and verify the same query succeeds without re-entry.
3. Make only terminal-recording search reject and verify event matches remain
   visible with a partial-result warning.
4. Reject Load More and verify existing rows remain with a retry action.
5. Run focused tests, i18n parity, typecheck, full tests, build and Search E2E.
