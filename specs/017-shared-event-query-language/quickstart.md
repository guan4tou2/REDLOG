# Quickstart: Shared Event Query Language

1. Record enough activity that every Transcript bucket has more than one page.
2. Type a term that appears only in the oldest evidence and confirm it is found
   without pressing Load Older.
3. Run the same query text on Search and on the Transcript and confirm both
   reach the same evidence under the same shared filter.
4. Query a tool-use ID whose call and result sit on different pages and confirm
   both halves appear as one block.
5. Paste a URL and confirm it is matched literally, with no condition read from
   the colon.
6. Mistype a field prefix and confirm the surface shows it was read as text.
7. Clear the query and confirm the view returns to its unqueried first page.
8. Interrupt the query path and confirm failure stays distinct from no match.
