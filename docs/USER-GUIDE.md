# RedLog 操作者手冊

寫給**使用** RedLog 的人，不是改它的人。目標：十分鐘內把一場行動記起來，並知道每個
畫面在回答什麼問題。介面與本手冊都是繁體中文。要接手開發請改讀
[`HANDOVER-2026-09.md`](HANDOVER-2026-09.md) 與 [`README.md`](README.md)。

對照版本：`main` @ v0.14.3。

---

## 一、RedLog 是什麼、不是什麼

**是**：一場紅隊行動的本機稽核日誌。它在背景被動記錄操作員與 AI 代理做過的每一件事
——指令、連線、檔案、畫面——蓋上時間戳、串成 SHA-256 證據鏈、可匯出成簽章證據包。
**發生過的，它就記下來了。** 時間軸若顯示 20 分鐘空白，那個空白是對的：你當時閒著，
或有一筆「已暫停」事件解釋它。

**不是**：報告產生器、ATT&CK 意見來源、關聯分析平台。那些留給下游（Ghostwriter /
HackerOne / SIEM）。RedLog 出廠**不裝**任何 MITRE 標記外掛——標記是每間公司自己的
意見。

## 二、開場十分鐘

### 1. 建立專案
開 app → 輸入專案名（例如 `Client-Pentest-Q3`）→ 建立。每個專案獨立存放設定、資料庫、
截圖與錄影，位於 `~/.redlog/projects/<id>/`。要預先設好範圍/白名單，展開「進階設定」。

### 2. 先跑一個指令（首次執行畫面）
新專案開在「先跑一個指令」畫面：一個內建終端機 + 右側即時記錄帶。在終端機打一道帶
目標的指令（例如 `nmap -sV 10.10.11.24`），右側亮起就證明**你打的東西正在被記錄**。
這是第一天唯一需要證明的事。其餘擷取來源收在下方「其他擷取來源」裡，不急著全開。

### 3. 接上真正重要的三個來源
RedLog **開著不等於在記錄**——要接上來源。按重要性：

| 想記的東西 | 接什麼 | 在哪裡 |
|---|---|---|
| 你自己終端機的每道指令 | Shell hook（Zsh/Bash）→ 啟用，再 `source ~/.zshrc` | 設定 ▸ Hooks 與終端機 |
| Claude Code / Codex 代理做的事 | 代理逐字稿 tailer（自動看 `~/.claude/projects/`） | 設定 ▸ AI 代理 ▸ 監看路徑 |
| HTTP/S 與 DNS 流量 | mitmproxy addon，或一鍵代理瀏覽器 | 設定 ▸ 網路與 IP，或標題列「開啟瀏覽器」 |

**務必設監看路徑白名單**：不設的話，tailer 會把你機器上**所有** Claude Code 對話
都吸進當前專案。把它設成這場行動的工作目錄。

儀表板的「擷取健康度」卡是例外報告：只在有來源沒在餵資料時才出聲。

## 三、每個畫面在回答什麼

側欄固定順序，⌘1..8 永遠對應同一畫面，數字印在右側；範圍/戰利品/書籤三列沒有數字
（用側欄點或 ⌘K 開）。頁面會隨資料出現才顯示——第一天只有四列是正常的。

| 畫面 | 回答的問題 | ⌘ |
|---|---|---|
| **儀表板** | 現在一切正常嗎？我暴露了嗎？記到多少了？ | ⌘1 |
| **時間軸** | 這段時間發生了什麼、順序如何、彼此的因果？ | ⌘2 |
| **搜尋** | 「password」「445」出現在哪些事件？ | ⌘3 |
| **逐字稿** | 把時間軸換個讀法：只看指令與 AI 對話 | ⌘4 |
| **HTTP** | 這場行動的 HTTP 往返歷史（logged 層） | ⌘5 |
| **終端機** | 內建多分頁終端，每個分頁自動錄成 `.cast` | ⌘6 |
| **截圖** | 縮圖牆 + 燈箱 | ⌘7 |
| **目標** | 從指令自動編目的目標，逐目標查證據 | ⌘8 |
| **範圍** | 有沒有打到範圍外？（違規紀錄 + 執法模式） | — |
| **戰利品** | 偵測到的憑證/機密，依類型、來源、信心度 | — |
| **書籤** | 你自己標的便條與網址（**注意**：書籤是便條本，不進證據包） | — |
| **設定** | 九個分類，左側有搜尋框 | ⌘9 |

### 時間軸怎麼讀
- **兩種形態**：任一泳道 >50 筆會整體折疊成事件流（時間仍對齊）。
- **游標為錨縮放**：Ctrl/⌘+滾輪、雙指開合都以游標下的位置縮放，不是畫面中心。
- **叢集**：一堆重疊事件收成一個點，點開跳到任一筆。
- **鍵盤**：`←→` 走同泳道、`↑↓` 跨泳道、`⇧←→` 跳下一筆帶狀態的、`f` 開因果鏈、
  `Enter` 開 Inspector。按 `?` 看完整快捷鍵表。
- **跳過閒置**：把 >10 分鐘的空白折成有斜線的斷口，密集工作拿到寬度。開著時軸不再等比。

## 四、行動中會用到的動作

- **標記發現**：⌘⇧M 隨處落一個標記（標題、嚴重度、描述）。標記是操作員的權威斷言，
  進證據鏈。要修正就再標一次（修訂是新的鏈上事件，不是覆寫）。
- **暫停/恢復**：⌘. 或狀態列。暫停時 RedLog 除了自己的稽核與明確標記之外**什麼都不
  寫**，每次切換都留一筆事件解釋時間軸的空白。
- **一鍵代理瀏覽器**：標題列「開啟瀏覽器」，透過你的 mitmproxy 起一個帶 CDP、專案獨立
  設定檔的 Chromium，流量與 QuickMark 不碰你的日常瀏覽器。
- **HUD 浮層**：常駐最上層的小視窗，顯示外部/內部 IP、即時跳板鏈、錄製狀態；外部 IP
  命中黑名單時整框閃紅（設定 ▸ HUD 可關）。

## 五、匯出與交付

標題列「匯出」是唯一的匯出入口（不在設定裡）：

- **全部（JSON）**：整條時間軸。
- **證據包（含驗證器）**：自帶 SHA-256 manifest 的資料夾，可交付，收件方用
  `ots verify` 與內附的 `redlog-verify.py` 獨立驗證。匯出前會走遮蔽閘。

命令列同一套：`redlog-cli export bundle`、`redlog-cli status`、`redlog-cli chain` 等。
`TOKEN=$(cat ~/.redlog/api-token)`、`PORT=$(cat ~/.redlog/api-port)` 後可直接打
REST API（只綁 127.0.0.1）。

## 六、術語對照（固定譯名）

Loot → 戰利品 · Scope → 範圍 · Marker → 標記 · Pivot → 中繼跳板 ·
Transcript → 逐字稿 · Anchor → 錨定 · Chain → 證據鏈。

保留不譯的技術詞：`IP · CIDR · SHA-256 · JWT · DNS · HTTP · mitmproxy · MCP ·
OpenTimestamps · CDP · WSL · hook · token · shell`。

## 七、常見卡關

1. **時間軸一直空的**：沒接來源。開著不等於在記錄——回第二節第 3 步。
2. **代理對話全被吸進來**：沒設監看路徑白名單（設定 ▸ AI 代理）。
3. **關掉 RedLog 後沒記錄**：正常。hook 讀 `~/.redlog/api-port`/`api-token`，只在 app
   開著、專案打開時存在——下班時間不記，是刻意的。
4. **macOS 說「RedLog 已損毀」**：是隔離旗標，不是壞檔。
   `xattr -dr com.apple.quarantine /Applications/RedLog.app`。
5. **`nmap -sS` 的封包沒被記**：SYN 掃描不完成握手，socket 層看不到。指令有記，封包
   沒有，這是不裝 pcap 就無解的物理限制。見
   [`DESIGN-traffic-attribution.md`](DESIGN-traffic-attribution.md)。
