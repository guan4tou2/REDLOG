## 4. 當日的決定

| 項目 | 決定 |
|---|---|
| API 權限 | 依能力分級：每個來源各發憑證，hook 與外掛只能寫入事件，不能匯出、刪除或切換錄製。已安裝的 hook 與外掛需重新取得憑證 |

| Bundle 版本 | 升版。新版本的 bundle 沒有相符的封存事件即驗證失敗；較早版本照舊驗證，另註明「未封存」 |

## 5. 未確認

各報告自己列出的未確認事項仍然有效，動手前需在對應環境確認。跨報告較重要的幾項：

- 暫停期間當機後重開，暫停時輸入的指令是否被補進正式紀錄（01-F4）。
- 主行程停頓時 curl 逾時，事件是否既寫入又暫存（01-F2）。
- 過短的 NTP 封包是否使主行程拋出未捕捉的例外（05-F4）。
- 離線且未開離線模式時，錨定失敗是否使「前後事件」面板顯示拒絕（07-F2）。
- 儀表板的證據鏈不一致紅字在正常擷取期間是否閃現（03-F3）。
- Windows 上「每次落在不同檔案」的失敗是否為整機停頓（06-F2）。
- 02 的絕對數字在高負載的機器上量得，比例可信，絕對值偏高。
