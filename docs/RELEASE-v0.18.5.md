# RedLog v0.18.5（封閉內測候選）

本版是封閉內測用的預發行版本，不是正式版。正式下載仍以 v0.18.3 為準。
v0.18.4 不包含下列修正，內測請改用本版。

## 安裝

- Windows x64：`RedLog.Setup.0.18.5.exe`。
- Kali／Debian／Ubuntu x64：`redlog_0.18.5_amd64.deb`，以 `sudo apt install ./redlog_0.18.5_amd64.deb` 安裝。
- macOS Apple Silicon：`RedLog-0.18.5-arm64.dmg`，拖入 Applications。
- 每份安裝包都列在 `SHA256SUMS.txt`。安裝前請先核對。
- 內測流程、升級、結束與移除方式見 `docs/INTERNAL-TESTING.md`。回報時請附上 commit、安裝包的 SHA-256、作業系統、重現步驟，以及預期結果與實際結果。

## 主要改善

- **擷取瀏覽器的 HTTPS**：RedLog 自己開的擷取瀏覽器經由內建代理時，以金鑰指紋信任代理的 CA。不必再把根憑證加進系統信任區；其他憑證照常檢查。
- **跨專案歸屬**：
  - 切換專案後才到達的 HTTP 回應、cookie 輪替與 DNS 結果，會歸屬到發出請求的專案，不再寫進新開的專案。
  - 被拒收的部分會在原專案留下缺口紀錄。
  - 資料庫會拒絕寫入不屬於目前專案的事件。
- **缺口看得見**：代理佇列滿時被拒收的事件，會以缺口記在時間軸上，並註明數量；連缺口都寫不進去時，擷取健康度會顯示遺失數量。暫停期間的缺口不會被當成遺失。
- **串流的結束狀態**：SSE／WebSocket 的詳情會說明串流是否正常結束、有幾段沒存到。被強制中斷而沒有結束紀錄的串流，標示為「結束狀態未知」，不再看起來像完整。
- **HAR 匯出**：只有串流片段、沒有請求／回應的 flow 不再被默默略過。預覽之後被改動的附件會讓匯出失敗，不會以原事件的 ID 交出改過的內容。
- **專案切換**：擷取瀏覽器的 profile 屬於開啟它的專案，切換或離開專案時瀏覽器會一起關閉，確認視窗會先說明。其他因切換而失效的背景工作（時間戳錨點、截圖、書籤、API 寫入）也不會再寫進下一個專案。
- **Git Bash 與 WSL**：
  - Git Bash 的指令會直接送達，不再走暫存，也不會延遲約 30 秒才入庫。
  - WSL 發行版在 `appendWindowsPath=false` 時，也能找到 Windows 版 RedLog。
- **匯出被拒時**：會說明是哪一項比對擋下的（事件數量、內容、設定、附件內容或附件數量）。
- **搜尋**：切換「非工作流量」篩選時，若剛好在輸入後 0.3 秒內，結果不會再被舊的查詢蓋回去。

## 驗證與限制

- CI（Windows、macOS、Ubuntu）全數通過；e2e 現在包含以真實 mitmdump 跑的擷取驗收。
- 已在真實環境驗收：Windows Git Bash 三種路徑轉換設定、WSL kali（mirrored networking）的來源選擇，以及以強制終止 mitmdump 驗證的串流結束狀態。
- **已知遺失**：強制結束代理時，最多 64 筆已進入佇列、尚未送達的事件，以及最後約一秒內被拒收的計數，可能遺失且沒有紀錄。
- **未驗證**：
  - WSL NAT networking；
  - 數小時的 SSE／WebSocket 長時間擷取；
  - PowerShell 5.1／7 完整的輸出與重啟矩陣；
  - 本版三個平台安裝包的實機驗收（內測第一輪會補上）。
- 安裝包未簽章：Windows 可能出現 SmartScreen（「其他資訊 → 仍要執行」），macOS 可能被 Gatekeeper 阻擋。
- 請勿把本版當成唯一的正式證據來源，也不要在內測中使用真實客戶的帳密或資料。
