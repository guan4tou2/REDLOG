# 內測快速開始

使用隨候選包提供的 `candidate.json` 核對 commit、平台與 SHA-256。公開下載的
0.18.3 不代表包含目前分支的修正；不要只看版本號。正式安裝路徑是 Mac DMG、
Windows NSIS、Linux x64 DEB，不需要 portable。Mac 目前未公證，下載隔離與
Gatekeeper 提示仍須另外驗收；本機候選正常啟動不代表這項已通過。

## 第一次開始紀錄

1. 建立測試專案。AI、剪貼簿及其他選用來源先保持關閉。
2. 選「記我的 Zsh／Bash／PowerShell 終端」，確認環境或手動改選，完成安裝後
   開新終端分頁。執行畫面上的 canary，確認收到該來源，不能只看「已安裝」。
3. 執行會產生 stdout、stderr 及非零結束碼的無害指令，到搜尋／逐字稿讀回。
   Bash/Zsh 一般指令自動保存有界輸出；PowerShell 要分別確認指令與輸出整合。
4. 做網頁測試才接 HTTP(S)：在「瀏覽器與 HTTP 擷取」準備、啟動代理，用你
   實際會用的 client 設定代理及信任 CA，再執行本次 HTTPS 驗證。代理正在執行
   不等於 client 已經過它；另一個 client 的成功也不代表你的瀏覽器已信任。
5. 已收到指令即可按「開始工作」。沒有使用的來源不需要為了消除提示而開啟。
   日常修復從擷取健康度直接進對應設定；HUD 預設顯示 IP。
6. 停止測試前，依查詢或網頁篩選預覽匯出，核對數量與附件，再開啟實際產物。
   關閉重開同一專案，確認原指令、輸出、附件仍可取得；證據包執行隨附 verifier。

## 不能當成「什麼都錄到了」

- `nc`、編輯器及 pager 等 native 類別刻意不擷取輸出；PTY session 是合併的
  終端輸出，不是原始鍵盤輸入，也不等同分離的 stdout/stderr。
- 重導向與工具輸出的檔案要另確認是否已加入證據；候選關聯不是產生者證明。
- 輸出有上限；完整性／截斷標記不能被忽略。App 不可達時的指令暫存不保證
  輸出可補回；無專案身分不能承諾保存，正常退出也會停止專案紀錄。
- 沒走 HTTP 代理的流量不會自動出現；nmap SYN、SMB、LDAP、RDP 不因此被解密。
- 網頁 scope 不篩指令。錄影可能含操作員資料或其他目標，交付前逐份檢查／排除。

## 升級、結束與移除

- 升級：直接執行新的安裝包（Windows 可 `/S`）。App 下次啟動時會把已接入
  shell 的 hook 換成新版，但升級前就開著的終端分頁仍是舊 hook，要重開。
- 結束：關閉視窗只會縮到系統匣／選單列並繼續記錄。從系統匣選「結束」後，
  有東西在記錄時會出現確認視窗，選「停止並結束」才退出；「留在背景」是取消。
- 開啟後沒有視窗：從系統匣選「顯示 RedLog」。仍沒有畫面時，以
  `RedLog.exe --disable-gpu` 啟動試試，並回報顯示卡型號與 Windows 版本。
- 移除（Windows）：解除安裝會先拿掉 PowerShell profile 與各 WSL 發行版 rc
  裡的 RedLog 那一行，升級則不會。專案資料**不會**刪除，交戰結束後依規定自行
  刪除 `%USERPROFILE%\.redlog` 與 `%APPDATA%\redlog`。macOS／Linux 沒有解除
  安裝程式，先在「設定 → 指令與終端」移除 hook，再刪 App 與 `~/.redlog`。
