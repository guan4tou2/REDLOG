# RedLog v0.19.0

本版包含 v0.18.6 之後合併的所有變更（#490–#804）。重點是介面依 Stitch 定稿重做，以及搜尋、匯出與資料可信度的大量修正。完整列表見 CHANGELOG。

## 安裝

- Windows x64：`RedLog.Setup.0.19.0.exe`。
- Kali／Debian／Ubuntu x64：`redlog_0.19.0_amd64.deb`，以 `sudo apt install ./redlog_0.19.0_amd64.deb` 安裝。
- macOS Apple Silicon：`RedLog-0.19.0-arm64.dmg`，拖入 Applications。
- 每份安裝包都列在 `SHA256SUMS.txt`。安裝前請先核對。
- 從舊版升級：直接執行新的安裝包即可，專案資料會保留。升級前請先看下方「升級注意」。

## 介面依 Stitch 定稿重做

- **專案啟動與選擇**：單欄版面、搜尋、範圍徽章。
- **儀表板**：需要處理、擷取狀態（指令與 HTTP 兩列，其他來源收合）、網路狀態、記錄概況、專案摘要。
- **活動紀錄與 Reader**：
  - 依時間的操作列，有來源徽章與結果碼，可在原處展開。
  - 共用一個 Reader，會說清楚指令輸出的去向。
  - 系統事件改為中文標題，連續三筆以上會收合成一列。
  - 沒有設定範圍時，事件標為「範圍未判定」，不再寫「範圍內」。
- **時間軸**：
  - 標準時間軸與多軌泳道兩種模式。
  - 兩列工具列，範圍預設會寫入共用篩選。
  - 密度波形上有可拖曳、可調整寬度的「重點視窗」。
  - 尺規上有「當前焦點」與「最新」標記。
  - 依實際欄位產生的卡片列。
  - 底部摘要列：單擊選取並顯示摘要，雙擊或 Enter 開啟詳情。
  - 縮放 100% 即為已載入範圍的全貌。
  - 全階段跨度改由後端計算，尚有更舊事件未載入時也能顯示。
- **證據**：截圖、戰利品、書籤三頁。檔案不存在的截圖顯示「無法載入圖片」。
- **終端機、目標與範圍、設定（單欄）、外掛管理、側邊欄**：都依定稿版面調整。
- 原型中資料無法支持的說法（推定拓撲、模擬狀態、示範文案）沒有照抄，改為依實際資料顯示。

## 搜尋與閱讀

- 活動紀錄的搜尋預設涵蓋終端錄影與 AI 原始逐字稿。
- 多個字詞的搜尋，可以跨同一次請求與回應比對。
- 展開的活動列提供「這筆前後的事件」。
- 戰利品命中可在原處查看來源，並保留返回路徑。
- Reader 的內容搜尋可比對寫成 `\uXXXX` 跳脫的文字。

## 匯出與證據

- 匯出的 bundle 會封存（bundle v4），附件會對照證據鏈檢查。
- 範圍遮蔽涵蓋參數、標頭、Cookie、URL 查詢字串與衍生列。HAR 也一律遮蔽。
- 匯出預設為整個專案。
- 大型匯出的選取、遮蔽與摘要移到背景 worker 執行，不再卡住主程式。
- Python 驗證工具的輸出與寫入端位元組一致，結果不再受系統語系影響。

## 擷取與資料可信度

- 每一筆新事件都記錄它是怎麼進來的，以及目標是怎麼判定的。全域目標不再套用到所有事件。
- 同一毫秒內的事件，會依記錄順序回傳。
- Shell hook 安裝到 shell 實際會讀的位置，且 shell 啟動時不輸出任何文字。
- AI 工具正在使用、但沒有被記錄時，會提示。
- 專案寫入改為 `synchronous=FULL`，已回報成功的寫入在斷電後仍會保留。
- `config.yaml` 讀取失敗時，會停止開啟專案，不再以預設值覆蓋。設定改為原子寫入。

## 移除

- 內建的 `transparent-proxy` 外掛（會以 root 改寫本機 nat 規則）。
- 剪貼簿監控。
- `redlog-share-worker/`，以及原本就已停用的 `hooks/vps-deploy.sh`。

## 升級注意

- **bundle v4**：舊版的驗證工具無法驗證 v4 bundle，請用本版附帶的驗證工具。本版的驗證工具仍可驗證舊的 v3 bundle，但會標示 NOT SEALED。
- **專案設定檔（profile）**：匯出的 profile 只包含範圍。舊格式（含 `network:`）的檔案會整份拒絕匯入。
- **transparent-proxy**：升級前若仍有 redirect 生效，請先以 root 執行該外掛的 `transparent-proxy.sh down <port>`。外掛移除後，就不再附帶這支腳本。
- **剪貼簿**：舊專案中既有的剪貼簿紀錄，會以一般 Reader 在系統軌道開啟。外部 API 不再接受 `agent_type: clipboard`。
- **IP 狀態**：只設定了「暴露 IP」清單時，不在清單上的位址現在顯示為「未知」，不再顯示為「安全」。
- **平台**：Electron 升級為 45，終端機元件升級為 xterm 6。

## 驗證與限制

- 發版時的 main（`19e7e4aa`）CI 在 Windows、macOS、Ubuntu 三個平台的 unit 與 e2e 全數通過。
- 介面有視覺參考截圖，並已逐頁比對 Stitch 原型。
- **本版尚未做已安裝套件的實機驗收**：
  - Windows NSIS 的安裝、升級與移除；
  - Kali／Debian 的 apt 安裝；
  - macOS DMG 的安裝；
  - 已安裝版本上的 HTTP／HTTPS 擷取與匯出驗證。
  這些項目沒有在本版重跑，不能視為通過。
- 安裝包未簽章：Windows 可能出現 SmartScreen（「其他資訊 → 仍要執行」），macOS 可能被 Gatekeeper 阻擋。
