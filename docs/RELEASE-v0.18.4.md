# RedLog v0.18.4

本版以「內測前把已知的漏記、誤導畫面與設定摩擦清掉」為主。

## 安裝

- Windows x64：`RedLog.Setup.0.18.4.exe`。
- Kali／Debian／Ubuntu x64：`redlog_0.18.4_amd64.deb`，以 `sudo apt install ./redlog_0.18.4_amd64.deb` 安裝。
- macOS Apple Silicon：`RedLog-0.18.4-arm64.dmg`，拖入 Applications。
- 每份安裝包都列在 `SHA256SUMS.txt`。macOS ZIP 保留為配套封裝；一般安裝使用 DMG。

## 主要改善

**擷取可靠性**

- 修正 macOS 上 `redlog-session` 偶發「結束碼 0 但沒有輸出」。根因是短指令在錄製端第一次讀取前就結束，系統在最後一個 slave 關閉時丟掉尚未讀走的資料；現在錄製端持有 slave 直到回收子程序並排空資料。這是 v0.18.2／v0.18.3 之後仍可能遇到的那筆漏記。
- Bash hook 在設有 `PROMPT_COMMAND` 時仍會記錄所打的指令；PowerShell hook 記錄指令實際執行的時間。
- 暫停期間的檢查不算數：錄製暫停時，擷取驗證不會被當成已驗證；專案紀錄會說明一段暫停，不依賴記憶體中的旗標。
- App 被強制結束或當機後留下的自有 `mitmdump` 會在下次啟動回收。

**設定與第一次使用**

- 預設路線改為：用你自己的瀏覽器，信任 CA。受管 proxy 以 Burp 式監聽位址提供，擷取用瀏覽器作為另一條路。設定頁同時顯示信任與移除信任的指令。
- 首次設定以外部終端為先，逐個 shell 驗證；已接上後折疊可選步驟。驗證結果若只是歷史紀錄會明說，並說明每個出口的作用。
- 首次設定頁的步驟順序與文案精簡，快速測試指向「終端機」選單。

**結束與移除**

- 結束 App 前會確認：若會停掉仍在錄的來源（包含外部終端）會先詢問。
- 移除 shell hook 會一併停止已載入它的終端；Bash 會明說已開啟的終端會繼續記錄到關閉。
- 停止 HTTP 擷取後，會告知有幾個窗格仍指向已停止的 proxy。

**證據與匯出**

- 匯出預覽會說明輸出是否被截短、錄製是否曾暫停；預覽時即時錄影固定在最後一行完整輸出。
- HAR 匯出不再在 50,000 筆後靜默丟棄；JSON 匯出不再夾帶操作者的私人設定；時間軸切片匯出在要求時確實清除操作者個資；已知失敗代碼附有說明。
- 手動加入的證據儲存後可被找到。
- 範圍測試器可測任一 URL、計入範圍檔並說明範圍檔是否生效，也說明匯出未過濾的部分。

**外掛**

- 外掛頁顯示 main 實際做了什麼、各項貢獻是否生效，可用貼上的文字試跑規則；失敗可恢復。信任變更會寫入稽核紀錄，被拒絕的遮蔽規則會被回報；同意說明不再宣稱沒有的隔離。

**畫面**

- 狀態列在窄視窗下維持單行，省略的資訊仍可由 Dashboard、提示與圓點按鈕取得。
- 時間軸不再把「範圍內」的命中顯示成範圍違規；暫停標籤改為說明性文字；狀態列會跟著已儲存的範圍更新。
- 新增「設定 → 關於 → 除錯日誌」開關：只記事件名稱、位元組數與完整度判定，不含指令、路徑或輸出，回報問題時可附上 `~/.redlog/debug.log`。

## 驗證與限制

內測範圍為 macOS Apple Silicon 加 Zsh。本版於該範圍以打包後的 App 完成：真實 zsh 的指令與失敗結束碼、受管 proxy 的 GET／POST、各頁面檢視、除錯日誌開關與不外洩內容；並以高負載壓測驗證上述漏輸出已消除（修正前 1600 次中遺失 15 次，修正後 0 次）。

- macOS 為 ad-hoc 封裝簽章，沒有 Developer ID 或 Apple 公證；Gatekeeper 可能阻擋，README 說明繞過方式。Windows 可能出現 SmartScreen 提示。
- 尚未驗收：真實 Chrome 加系統 CA 信任的 HTTPS、另一台 Mac 的 DMG 下載／Gatekeeper／Dock 啟動、完整人工首次安裝計時。Windows 與 Linux 安裝包由 CI 建置與冒煙測試，沒有在本輪人工操作；原生 WSL 不在內測範圍。
- 外部 Zsh 可自動留下有界輸出；Bash／PowerShell 的普通 hook 主要記錄指令與退出資訊，輸出請使用已驗證的內建終端或對應錄製方式。
- 來源狀態、工具安裝成功與完整流量覆蓋是不同的事；請完成 Capture setup 的指令、輸出及 HTTP／HTTPS 驗證。
