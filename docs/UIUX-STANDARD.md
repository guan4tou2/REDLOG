| `danger`（危險紅） | 與品牌紅同色 | `#ff4d4f` | 實心底 + **深色字 `#1a0303`**（6.1:1），僅危險 |
| `lane` | 18 種色相 | `#6e6e78` | 全部泳道統一 |
| `safe` / `warn` / `info` | `#5ecf9c` / `#d4ac5a` / `#3fc7d6` | 不變 | 狀態 |

**紅色語意收緊**：品牌紅只在**命令按鈕**上填色，其餘一律只做文字或細線；危險紅只填色，且可以填在任何地方。區別不靠「有沒有底色」，而靠「這是可以按的動詞，還是在報告狀態」。硬限制：**同一個動作區（對話框底部、工具列、卡片頁腳）不得同時出現實心品牌紅與實心危險紅**。搭配「一屏最多一顆主要按鈕」與「全 app 同時只允許一處危險紅」，這個情境不會發生。

**填色一律配深色字**：這個色盤的彩色全是中亮度，白字在每一個上面都不過 AA——`#d75f63` 3.68:1、`#ff4d4f` 3.27:1、`#5ecf9c` 1.93:1、`#3fc7d6` 2.03:1。深色字全部過 5:1 以上。所以規則不分顏色、不分元件：**填色就配深色字**，涵蓋按鈕、徽章、chip、進度標示。

| 填色 | 配的字色 | 對比 |
|---|---|---|
| `accent` `#d75f63` | `on-accent` `#16090a` | 5.3:1 |
| `danger` `#ff4d4f` | `on-danger` `#1a0303` | 6.1:1 |
| `warn` `#d4ac5a` | `on-warn` `#1a1203` | 7.2:1 |
| `safe` `#5ecf9c` | `on-safe` `#03150d` | 9.7:1 |
| `info` `#3fc7d6` | `on-info` `#031215` | 9.4:1 |

不調暗 `#ff4d4f`——它的亮度正是與品牌紅拉開距離的手段。也不另開第三個紅。

**狀態唯一真相表**

| 狀態 | 色彩 | 唯一允許的表現 |
|---|---|---|
| 正常／安全 | `#5ecf9c` | 圓點 + 文字，無實心底、無動畫 |
| 未知／閒置 | `#d4ac5a` | 圓點 + 文字 + 一句「怎麼補」 |
| 危險／違規 | `#ff4d4f` | 實心徽章或實心按鈕，`on-danger` 深色字 |
| 錄製中 | `#d75f63` | 閃爍圓點，僅狀態列與 HUD |
| 資訊／連線 | `#3fc7d6` | HUD 邊框、拓樸、minimap；不用於狀態判定 |

狀態絕不只靠顏色——圓點必須配文字或形狀。

## 2. 字型與字級

- 介面字 `Noto Sans TC`（隨 app 打包，三平台一致）；等寬字 `JetBrains Mono`
- IP、hash、exit code、時間、事件數一律等寬 + `tabular-nums`
- 硬下限 **13px**（現有約 155 處 `text-[10px]` / `text-[11px]` 需清除）
- 數值 22px/600 · 畫面標題 17px/600（不再全大寫）· 內文 15px/1.7 · 分區標題 13px/600 tracking .14em
- HUD 是唯一例外：下限 11px（有自己的縮放設定）

| `--row-h` | 40px | 32px | 側欄項、泳道列、清單列 |

## 4. 元件

- **標誌**：單一字標 `REDL(●)G`，O 為錄製指示環。介面內不再並列「R」方塊與字標。環全部以 em 表示（換字級不必重算）：外徑 `0.72em`（= Noto Sans TC 大寫字高）、環寬 `0.115em`（外徑 16%）、內點 `0.216em`（外徑 30%）、上移 `0.02em`；環必須 `box-sizing: border-box`，用 content-box 會讓外徑多出兩倍環寬。字標下限 12px。切角符號只用於 app 圖示、Dock、系統列、favicon，切角 = 邊長 22%（固定左上／右下；HUD 面板用的是 `lib/hud.ts` 的固定 11px／5px，因為面板尺寸不一，標誌是等比縮放所以改用比例），16px 以下環收成實心點。標誌永遠 `#d75f63`，不用危險紅、不動畫；單色場合用 `#ececf0` 或純黑；留白 ≥ 環直徑
- **按鈕**四級，高 34px（緊密 30px），圓角 8px，focus 環 2px `#d75f6366` 外偏移 2px。同一畫面最多一個主要
  - 主要 = 實心 `accent` + 深色字（`#16090a`）。這是 §1 允許品牌紅填色的唯一場合
  - 次要 = `elevated` 底 + 1px 邊框；安靜 = 純文字；危險 = 實心 `danger` + `on-danger` 深色字
- **卡片**：取消頂部 2px 色條，改為左側色塊包住圖示（危險用實心，其餘用 12% 底色，與徽章規則一致）。卡片底色永遠是 `surface`，不因狀態改變
- **徽章**：12% 底色 + 同色文字 + 圓點；只有危險用實心
- **chip**：選取時 `elevated` + 1px 邊框，不用紅色
- **輸入框**：placeholder `#6a6a74`；IP/CIDR/路徑類一律等寬
- **圖示**：Lucide，1.5px stroke，尺寸只用 16/20/24px（取代 `◉ ▸ ═ ☰ ◻ ⊕ ⊘ ◆ ⚑`，這些 Unicode 在 Windows 落到不同 fallback）
- **載入**：<300ms 不顯示 · <2s 行內 spinner · >2s 骨架屏 + 進度文字（骨架尺寸須與真實內容對齊）

## 5. UX 原則

1. 一屏只回答一個問題——每畫面選一個主問題給最大字級，其餘降為單行摘要
2. 例外報告，不是清單——預設只顯示異常，正常收成一行 +「顯示全部（N）」
3. 導航順序固定，⌘1..9 永遠對應同一畫面，數字印在側欄右側
4. 空狀態三件套：會出現什麼／為什麼現在沒有／一顆按鈕
5. 危險操作分三級：可逆→直接執行 + Toast 附復原；不可逆→對話框 + 勾選框；影響證據鏈→輸入專案名確認 + 列出具體後果
6. 全中文介面，技術詞白名單：`IP · CIDR · SHA-256 · JWT · DNS · HTTP · mitmproxy · MCP · OpenTimestamps · CDP · WSL · hook · token · shell`。固定譯名：Loot→戰利品、Scope→範圍、Marker→標記、Pivot→中繼跳板、Transcript→逐字稿、Anchor→錨定、Chain→證據鏈
7. 符合 macOS 慣例：設定為左清單 + 右內容；⌘. 暫停、⌘K 命令面板、⌘F 頁內搜尋、Esc 逐層退出；破壞性動作在對話框右下（Windows 自動對調）；tooltip 不得是唯一的資訊來源
8. 可及性硬門檻：文字 ≥4.5:1、非文字狀態元素 ≥3:1、focus 環處處可見、`prefers-reduced-motion` 保留

## 6. 時間軸

- **兩種形態**：可視範圍內任一泳道 >50 筆 → 全部泳道一起折疊成事件流（保持時間對齊）；使用者手動改過模式後，本次 session 不再自動切換
- **事件流每列**：時間戳 + tier glyph + 泳道名 + 一行摘要。保留泳道篩選（逐字稿則固定只看指令與對話）
- **Inspector**：右側 380px 可拖抽屜，三分頁〈詳細／相關／原始〉。「相關」就是全局因果鏈面板，不另建。預設關；視窗 >1600px 預設開
- **滑鼠**：滾輪捲時間；Ctrl/⌘+滾輪與雙指開合**以游標為錨**縮放（不是畫面中心）；雙擊空白處縮放到前後 5 分鐘
- **鍵盤**：← → 同泳道走；↑ ↓ 跨泳道落在時間最接近的事件；Shift+← → 跳下一筆帶狀態的事件；Home/End；+ − / 0 以選中事件為錨；Enter 開關 Inspector
- 鍵盤移動必須有可見選取框（2px 品牌紅外環 + 事件點 1.3×）；自動捲入視野**不得改變縮放層級**
- ~~**檢視模式**（取代工具列八組並列開關）：作業中／稽核／除錯~~ — **▲ 分歧**：已實作後 revert（`59ff5fc`，人設硬套旗標組合、預設落在「除錯」）。現行做法：切換**按作用分組**，罕用的檢視／稽核項收進〈更多〉overflow（`48713ba`）；18 泳道另按擷取組分帶（`183b9ac`）。

## 8. HUD

- 排版：左端兩點（錄製、安全狀態）→ 外部 IP（最大字級）→ 內部 IP 右對齊
- 位置：頂部置中**偏右**（避開 MacBook notch，靠近選單列狀態區）；每台螢幕分別記住位置
- 透明度：預設 0.85，游標移入轉 1.0（因此**滑點預設關**）
- 展開態四段固定順序：鍵值表 → 網路拓樸 → 警告列（僅未知 IP 或錯誤）→ 動作列（快速標記／仔細標記／固定）。標籤欄寬隨字級縮放
- 跳板節點：收合態在外部 IP 下方長出青色切角膠囊（最新節點 + `+N`）；展開態按時間把每一跳插進鏈中。**這是唯一允許在收合態長高 HUD 的元素**
- 穿透按鈕：放展開態動作列；必須有 `⌘⇧P` / `Ctrl Shift P` + 選單列作為不靠點擊的退出，並在開啟瞬間浮出 3 秒提示；穿透中整體降透明、四角改虛線，但外部 IP 維持不透明
- IP 暴露時強制解除穿透、轉為不透明、固定展開——唯一允許覆寫使用者偏好的情況

## 9. 錯誤、狀態與資料量

- **錯誤訊息三段式**：發生什麼事（中文）+ 為什麼 + 一顆動作；原始錯誤收在「詳細」折疊區
- **Toast**：錯誤不自動消失；同類合併計數；上限 3 則；容器需 `aria-live="polite"`（錯誤用 `assertive`）
- **持續性故障**分兩層固定在狀態列左側：〈需要注意 N〉只收影響證據的（抓取中斷、錨定失敗、鏈斷、DB 寫入錯誤、檔案遺失）—— **不可忽略**、紅點；其餘收〈待處理〉—— 可忽略、灰色、不寫稽核
- **時間**：一律 24 小時。相對時間**只用於新鮮度欄位**（最後一次抓取、3 秒前）；事件本身、時間軸軸標、逐字稿、匯出一律絕對時間，匯出用 ISO 8601
- **文字截斷**：一律可 hover 看全文（原生 `title`），長內容另可展開成多行
- **大量資料**：全部改無限捲動 + 虛擬列表，底部顯示「已載入 N／共 M」。目標頁改 SQL 聚合（`GROUP BY detectedTarget`），不再讀 1000 筆原始事件在前端聚合
- **致命錯誤畫面**：錯誤摘要 + 〈重試〉〈回儀表板〉〈複製診斷資訊〉+〈開啟 GitHub issue〉。診斷資訊預設只帶版號、OS、畫面名、stack；送出前顯示完整預覽；路徑收成 `app.asar` 之後的相對路徑，使用者名與專案名換成 `<user>` / `<project>`
- **清單頁鍵盤**：方向鍵走、Enter 展開／進入、⌘↩ 跳時間軸、Esc 退出——全部清單頁一致
- **對話框**：需 focus trap（目前三個 `role="dialog"` 只有 autofocus）

- **〈顯示 N 個機密〉與本機遮蔽全部刪除** —— 資料已在使用者自己的機器上。**例外：進入證據包、任何匯出的資料仍須經 redaction**（▲ 雲端分享與藍隊 webhook 已移除），這條線要在程式裡分開實作

## 22. 漸進揭露

一條規則：**名詞在它的資料存在之前不出現。** 第一天側欄只有四格（儀表板、時間軸、終端機、設定）。隱藏不等於不可達——⌘K 一律列出全部視圖，快捷鍵照常開啟原本的頁面，外觀頁還有一個總開關。

**解鎖對照表**（`lib/visibility.ts`；括號內是該訊號所在的層）

| 名詞 | 等到什麼 | 為何是這個訊號，不是更寬鬆的那個 |
|---|---|---|
| 搜尋 | 任一筆「操作員做的事」（兩層） | 判定用 `EVIDENCE_SQL` 這個**正面**述詞，不是「非 housekeeping」。alert runtime 每次開專案都會啟動，IP policy 無條件送出第一筆判定（離線也會送 `unknown`），所以幾秒內就會有一筆非 housekeeping 的上鏈列 |
| 逐字稿 | 已完成的指令，或任一 agent 回合 | 就是該頁實際渲染的兩種列 |
| 目標 | 由**指令**推導出的目標 ≥1（上鏈） | proxy addon 對每筆 HTTP／DNS 都會蓋 `target_id`，連線監控對每個 socket 也會——跨型別去算，一次瀏覽器開頁就會解鎖，正好與本節的規則相反 |
| 範圍 | 同上，≥2 | |
| 戰利品／截圖 | 自己那一型的上鏈列 | `loot:getCount` 是記憶體計數器，重啟歸零，不是資料 |
| 標記 | 一筆 `quickmarks` 列 | 該頁只列這張表；`marker` 事件是另一個儲存區，而且可由外部 POST，用它會讓外部工具解鎖一張空頁 |
| HTTP | logged 層的 `http_request_start` / `http_response` | 該頁只查 logged 層。上鏈的 `scanner:connection` 會解鎖一張永遠空著的頁 |
| 層級字符（Inspector chip） | 任一 logged 列，或 `system.retention_pruned_logged` 稽核列 | 稽核列比它描述的資料活得久，所以 logged 層被清空後字符不會消失——否則會被讀成「這個層不見了」 |
| 錨定／跳板節點 | 無需程式碼 | 儀表板的 ⚓ 子行與 HUD 膠囊本來就以資料為條件 |

**工程約束**
- 可見性由資料推導、**不存使用者狀態**（唯一例外是 5c）；`visibility.ts` 是純模組，不碰 React、window 或 core。
- **單調**：出現過的名詞不再消失。logged 層 30 天後會被清，頁面若因此消失會被讀成證據被銷毀。
- ⌘ 編號取自 `DEFAULT_ORDER` 的位置，不是渲染位置——隱藏一列不會讓其他列換號。
- `null` 訊號代表「還沒問到」，不等於「還沒有」：外殼會等專案與訊號都回來才畫，否則成熟專案會閃一下四格側欄。探測失敗時**全部顯示**。
- 重新探測有兩道閘：只有可能打開尚未開啟之閘的列才算，且要等該批事件安定；全開之後解除訂閱。

**5c** 外觀頁的「一次顯示所有頁面」是**按專案**存的（localStorage）。切專案是同源 reload，全域鍵會讓一次勾選對之後每個案子永久生效；也不放 config.yaml，因為它會隨交接檔旅行。

**9a 首次執行單一路徑**：一個畫面一件事——在內建終端機打一個指令，右欄的時間軸長條亮起。十個擷取來源降為底下一個折疊區（原封不動的 `CaptureHealthCard`）。畫面狀態是**閂鎖**的，不是直接讀 `firstRun`：後者在第一列進來的瞬間就翻面，而那正是這個畫面要讓人看到的一刻。開始打字十秒後仍無事發生，右欄改說真正的原因（內建終端機的掛勾需要 python3 與 curl）。
